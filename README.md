# Grove — Deep Listening Rebuild

A single-file GitHub Pages build.

## Publish
Replace the current `index.html` in the `adedejiayobami0-ux/groove` repository with this `index.html`.

No build step, framework, external CSS, or JavaScript files are required.

## Working interactions
- Home, Explore, Journal, and Session views
- Search and genre filters
- Guided listening sessions
- In-browser original demo audio via Web Audio API
- Play/pause, seek, previous, and next session controls
- Timestamped journal notes
- LocalStorage persistence for notes
- Responsive mobile layout
